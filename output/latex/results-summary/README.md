# Research results summary

A one-page LaTeX results section with no title page or abstract. It reports the main findings, a vector figure, numerical controls, and limits of the evidence.

Compile from this directory with Tectonic 0.17.0:

```bash
tectonic results.tex
```

The figure is reused from `output/latex/research-paper/figures/fig1-recovery-compression.pdf`. Its metadata preserves source paths, hashes, populations, and aggregation. All quantitative findings use saved reference results at scientific commit `e06479ce09f10695aa5280162f80d880c060eaf5`. No model training or scientific experiment is rerun to build this document.
