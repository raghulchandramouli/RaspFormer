# Concise research findings

This version starts with the results. It has no title page, author block, abstract, or long introduction. It retains the essential methods, eight experimental findings, one vector figure, limitations, and evidence links.

Compile from this directory with Tectonic 0.17.0:

```bash
tectonic brief.tex
```

The final PDF is `output/pdf/raspformer-findings-brief.pdf`. The editable source package is `output/pdf/raspformer-findings-brief-source.zip`.

The figure is reused from the concise research paper and is derived from canonical reference data. Its metadata retains input paths and hashes. No scientific experiment is rerun to compile this document.
